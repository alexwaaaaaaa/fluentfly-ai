## Backend Modules

### Core Modules
- **auth**: JWT authentication, Google OAuth, Phone OTP
- **users**: User profile management
- **lessons**: Lesson content and exercises CRUD
- **progress**: User progress tracking
- **gamification**: XP system, streaks, badges, leaderboard
- **chat-ai**: AI conversation with Gemini/OpenAI
- **speech**: Azure TTS/STT integration
- **rtc**: LiveKit token generation
- **storage**: S3/R2 file storage

### Infrastructure
- **TypeORM**: PostgreSQL database ORM
- **Redis**: Caching and session management
- **Swagger**: API documentation at /api/docs
- **Throttler**: Rate limiting (100 req/min)

## Database Schema

### Tables
- `users` - User accounts (email, phone, xp, streak, level)
- `lessons` - Lesson content (skill, title, level, metadata)
- `exercises` - Individual exercises (type, question, options, answer)
- `progress` - User progress (scores, completion status)
- `chat_sessions` - AI conversation history
- `badges` - Achievement definitions
- `user_badges` - User badge awards

### Indexes
- `idx_lessons_level` - Fast lesson filtering by level
- `idx_progress_user_id` - Fast progress queries by user
- `idx_chat_sessions_user_id` - Fast chat history retrieval
- `idx_users_xp` - Fast leaderboard queries

## Mobile App Structure

### State Management
- **Riverpod**: For reactive state management
- **Hive**: Local database for offline caching
- **SharedPreferences**: User preferences storage

### Key Dependencies
- `dio`: HTTP client for API communication
- `flutter_riverpod`: State management
- `hive`: Local storage
- `lottie`: Animations
- `audioplayers`: Audio playback
- `record`: Audio recording
- `cached_network_image`: Image caching

## Docker Services

The docker-compose.yml configures:
- **api**: NestJS backend (port 3000)
- **postgres**: PostgreSQL 16 (port 5432)
- **redis**: Redis 7 (port 6379)
- **livekit**: LiveKit server (ports 7880-7882)

## Environment Variables

See `backend/.env.example` for all required configuration:
- Database connection
- Redis connection
- JWT secrets
- Firebase credentials
- Azure Speech API keys
- Gemini/OpenAI API keys
- S3/R2 storage credentials
- LiveKit configuration

## Next Steps

1. Configure environment variables in `backend/.env`
2. Start services: `docker-compose up -d`
3. Access API docs: http://localhost:3000/api/docs
4. Run mobile app: `cd mobile && flutter run`
